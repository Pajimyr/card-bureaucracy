# Retrospektiva

Každý člen píše **vlastní, krátkou** retrospektivu do `docs/retrospektiva/<jmeno>.md`. Stačí půl strany. Tři otázky:

1. **Co bych udělal jinak?**
2. **Kde mi AI pomohla?**
3. **Kde mi AI překážela?**

Pište konkrétně: místo „AI pomohla s kódem“ napište „AI napsala generátor pixel artu v Pythonu, sám bych grafiku kreslil týden“.

## Šablona

```markdown
# Retrospektiva: <jméno>

## Co bych udělal jinak

## Kde AI pomohla

## Kde AI překážela

## Jedna věc, kterou si odnáším
```
